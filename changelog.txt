[B]Trakt Style 1.2.2[/B]
- Home rows longer than the screen can now be paged with the mouse / touchpad: hovering a row shows ‹ › arrows at the right end of its header; they scroll the row a page at a time without moving the focus. Keyboard and remote navigation is unchanged

[B]Trakt Style 1.2.1[/B]
- Mouse wheel / touchpad on the home screen now moves between rows (the page scrolls) instead of scrolling the row under the pointer sideways; rows still scroll sideways with Left/Right. Done with a small keymap the skin writes to userdata/keymaps (skin.traktstyle-home-wheel.xml); can be turned off in Skin settings > Home screen
- "Backdrop of the focused title on the home screen" is now off by default

[B]Trakt Style 1.2.0[/B]
- Elementum menus get their own icon set (Movies, TV Shows, Search, Torrents, Add Torrent, History, Providers, Changelog, Status, Donate, Settings, every Trakt/TMDB list), picked by each entry's path and tinted with the theme colour
- Elementum's main menu keeps big tiles; the Movies / TV Shows menus, search history, torrent history and other add-on menus use compact two-line cards
- Menu screens get a page header (e.g. "Elementum", "Search")
- Back from Elementum's main menu (or the Video add-ons list) goes to the home screen instead of Kodi's Videos screen
- The start-up jump into Elementum now opens from the home screen, so Back returns there

[B]Trakt Style 1.1.0[/B]
- New video player look: now-playing block (poster, S/E, title, episode name), quality pills, end time, thick rounded progress bar with chapter marks, round controls with a big play button, logo + clock strip on top, plot and "up next" on Info
- Elementum's playback status box now sits above the player panel instead of over it (16:9 is listed first in addon.xml, which Elementum reads to place the box)

[B]Trakt Style 1.0.1[/B]
- Home: arrow keys now move between the rows and the Media / Shows / Movies tabs
- Home: the left icon rail works with arrow keys (up/down inside it, right back to the rows)
- Elementum screens only use the Trakt views (poster grid, episode grid, carousel), so a view saved by a previous skin or forced by Elementum's "Default view" settings no longer shows an unthemed Estuary view
